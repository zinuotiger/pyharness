# 配置历史与兼容恢复

模型配置和 Agent 管理卡片均提供“配置历史”。当前团队管理员可管理本团队的历史；本地操作者沿原权限访问。成员和只读账户不能读取这些私有配置记录。

1. 刷新当前状态，选择“保存当前配置版本”。模型保存公开参数与原凭据代次引用；Agent 必须先发布，历史引用原发布版本。未发布草稿不会被自动覆盖。
2. 选择固定版本，查看差异与兼容性。凭据轮换、依赖变化、废弃版本或损坏资料会阻止恢复。处理原因后重新预览，不能强行替换成当前秘密。
3. 勾选应用确认；若有权限、预算或执行范围扩大，还需单独确认列出的扩大项。该确认不能替代实际任务的工具审批。
4. 明确应用。模型恢复会激活该连接；Agent 恢复会创建新的发布版本。旧版本、在途任务上下文、日志与尝试不被改写；新任务继续经过原执行检查。

响应超时或断线时保留原命令键，使用“查询本次原命令”。不要盲目重发。重新打开页面后，展开“最近 20 条已提交命令”可以查询原回执；当前凭据不可用时，历史记录与原已提交回执仍可查询。未找到原命令不证明在途请求已经结束，先确认原提交状态。

历史最多保存 128 个版本、256 条命令，达到上限会明确拒绝，不静默删除。回执表示当时提交结果，不能证明当前配置仍兼容。时间由服务端记录；旧命令没有时间时显示未知。

此功能不备份或恢复秘密值、宿主文件、技能或知识正文、运行记录和外部动作，不提供跨模型库和 Agent 库的整体原子恢复。兼容预览只核对元数据和当时可读的依赖；没有运行网络、MCP、Codex 或远程沙箱测试。实际任务仍会重新检查并固定依赖。

界面关闭、导航或身份变化后清除私有展示与内存，不在浏览器持久存储历史内容。公开字段仅经过有限模式及已知秘密值检查，不应将密钥写入名称、提示词或其他公开文本；此过滤不能替代内容审查。
