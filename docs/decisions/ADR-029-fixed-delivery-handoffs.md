# ADR-029 固定交付产物、具名交接与独立验收

状态：已实现，S10整体验收进行中。日期：2026-10-19。对应C02/C04与A02；遵循原单进程owner、SessionLog真源、强确认和权限单调收紧。

## 决策

交付不是一段模型自报的成功文字。新交付包绑定原ExecutionAuthorization、RunAttempt当时已经选择的DeliveryDefinition及同一正式任务版本。每项输出必须来自该次实际执行或原日志证明的已准入子任务：原`platform.artifact/generated`记录及当前物理文件，或原`agent.message`公开最终文本。保留事件序号、记录摘要、内容SHA256、大小和真实会话/任务身份。上传文件ID、任意路径、私有推理或完整模型上下文不能冒充生成产物。文件为空可以是合法产物；必交项目缺映射、伪造handle或字节变化均不能得到有效冻结包。

角色、交接、签收、验收与导出是原控制日志上分别强确认的资源；不另建任务数据库或第二份运行事实。角色绑定同租户真实账户UID，服务端解析用户名并再次核对当前成员关系。Agent名称、客户端actor、租户字段或Agent发布版本均不能替换该主体。生产者可把输出交给自己名下的另一个固定Agent，但独立验收始终要求与生产者不同的真实账户。

审阅角色不选择Agent，也没有执行额度。承接角色固定已发布Agent版本；工具、MCP、技能、知识源只能取父权限子集，内存与权限策略不能放宽，执行器及沙箱身份不变，资源和预算上限不能增加。交接只授予明确产物子集及最小说明。读取不自动签收，签收不自动验收，工具审批不代替业务验收。验收逐个固定项目/标准记录`pass/fail/unknown`；不能把未知结果算作通过。

导出必须另有对具体承接账户、具体交接和具体输出的授权。审阅导出允许在业务验收之前明确授予；交付导出必须绑定当前有效的独立验收。它不修改旧ArtifactRecord的下载标志，不借旧工具审批授予导出。每次下载前后重核授权与原始字节，采用附件响应、`no-store`与`nosniff`；不执行HTML、SVG或PDF中的主动内容。

## 承接资料与原执行链

新增显式document blob schema2保存选定公开产物的引用快照；旧document schema1、原RunAttempt schema1/2/3、ExecutionAuthorization与图schema不增加默认字段，避免改变既有命令摘要。文本保持Unicode codepoint区间和摘要；PDF走原独立、一次性、有时限及内存/输出上限的解析器，先预览、再确认导入，保留真实物理页及不可定位页。PDF不能塞进普通文本输入。资料只进入既有`AttemptContext.document_refs`和原引文定位，不导入父会话的messages、系统提示或运行状态。

承接资料由实际接收主体持有，但每次使用仍检查当前交接、签收、角色、独立验收、来源授权与原输出字节。下游产物继续核对上游承接依赖；撤销上游审阅者成员资格不能靠再产出一个包洗掉失效。依赖遍历最多20层，遇循环或无法确认时拒绝。校验过程保持真实请求者身份，存储的生产者UID仅定位其历史元数据。

原普通任务和原DAG节点共用同一承接准入。图定义阶段就拒绝与固定承接Agent不符的选择；实际运行仍通过原Queue、AgentLoop、Scope、Guard、Approval及准备/模型/工具边界。原执行详情投影与交付中心读取同一当前业务验收结论；新包、新结论、标准修订或依赖撤回使旧结论失效，原历史事实保留。

## 预算预留与恢复

每次承接执行在原ExecutionAuthorization之前，以同一控制锁强确认不可变`handoff_budget`。按已完成父日志、已确认状态预算、尾部实际usage、已准入子任务以及所有既有预留，核对输入、输出、工具数、整数微元、轮数和时间。只使用可确认的运行时成本估计，不把未知成本当零，也不冒充供应商账单。子任务的完整声明额度先预留；完成、失败、取消或换一个请求键不自动归还该上限。相同执行/尝试/角色只对应同一预留，未知授权回执不能自动重投旧执行。

保存交付、角色、签收、验收、导出或资料均不自行启动模型。浏览器只保存按真实主体/项目隔离的原键、资源ID和请求摘要，不保存私有交接正文；恢复只读核对，重试须保留同一选择与摘要。冷读取交接、独立验收、导出和原键不构造控制写者、Queue或Engine。旧普通项目/文档页面仍保留原写者打开行为，不宣称所有旧GET均零写者。

承接执行的通用S08续做入口目前在准入前明确拒绝`handoff_continuation_requires_budget_admission`，只读计划同样列出阻断。它不能通过创建新attempt重置预留；普通未绑定承接资料的S08续做不变。新建下游尝试/新图是明确的新任务，不能称为旧Root自动恢复；未来产物不会隐式注入一个已冻结图。

## 验证与范围

依照S10当前源码证据验收：真实账户认证、普通成员签收/独立验收及越权拒绝，实际生成文件/PDF，预算争抢，撤权传递，未知提交原键查询，原执行器与DAG消费，真实Chrome、完整HTTP、全量回归及安装入口。测试推理使用ScriptedAdapter；真实HTTP、实际文件/进程、Chrome与Docker证据分别记录，不用模拟推理冒充真实付费提供商或外部系统接入。S11写回、S12观测等后续阶段不由本决策提前宣称完成。
