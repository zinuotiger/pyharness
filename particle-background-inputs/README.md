# 六款浅色粒子背景：设计输入包

## 包内是什么

- references/：当前对话已经生成的六张原始效果图，逐张原样复制，包含文字和示意界面。
- REFERENCES.json：原图、拟用背景 ID、真实像素尺寸、文件大小及 SHA-256 的对应表；这是设计参考清单，不是生产环境的背景注册表。
- BACKGROUND-BRIEFS.md：六款无文字、无界面的纯背景制作要求。
- CODEX-TASK.md：交给 Codex 的增量开发任务。

## 不是什么

本包不含已经去掉 UI 的纯背景，不含项目源代码修改，也不代表当前项目已经完成接入或验证。六张原图均为 1672 × 941 像素；没有放大或宣称为原生 4K。

## 放置位置

将 particle-background-inputs 文件夹整体放在你正在使用的 pyharness-platform-web-v1 项目根目录下，再让 Codex 阅读其中的 CODEX-TASK.md。这里的目录是建议新增的输入位置，不是已确认存在的项目路径。保留已存在的同名个人文件，不要覆盖。

生产素材应由 Codex 在确认真实项目结构后放到已有静态资源目录。不要把 references/ 中带假窗口的图片直接当作正式应用背景；设计参考目录也无需打进生产包。
