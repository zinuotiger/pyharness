# 项目资料与交付要求

进入“项目空间”，在活动项目上打开“资料与交付要求”。这里定义资料和交付标准；实际执行与独立验收由后续任务流程接入。

1. **添加文本资料**：选择已准备的私有输入，点击读取文件清单，选中明确文件并填写标题，再保存。阅读只使用那一份捕获内容，不会暗中重新读取宿主正文。
2. **添加PDF**：先在项目的“只读源授权”中授权目录；选择该授权，填写目录内PDF相对路径，点击预览、核对并勾选确认，再保存。更改选择后需重新预览。
3. **阅读与引用**：在资料列表选阅读版本。PDF显示真实物理页和提取段落，空白/扫描页提示不可定位。点击“引用此段”可调整Unicode字符区间，保存后在“保存的引用”定位原文。
4. **定义交付要求**：切到“交付要求”，选择正式产品任务，添加必交/可选项目、逐项验收标准和依据引用。保存只形成清单，不会让任务执行或自动通过验收。
5. **修订与失效**：修订产生新版本，旧引用仍指向原版。源变化、资料新版、输入/项目/解析器变化会提示过期；源缺失/资料退役不显示旧正文，授权撤销或到期则拒读。不要把旧版过期提示当成新版内容。
6. **保存未确认**：出现断线/未知结果时，界面保留原命令，可选择只读核对或原键原正文重试。不要另建重复对象；关闭整个浏览器后应从服务端列表检查已有版本。

支持UTF8/BOM文本及文本层PDF；HTML/Markdown只显示文字，不运行脚本。未提供OCR、Office解析或原PDF像素排版。PDF最多2MiB/200页；文字、段落和处理时间另有上限，超限会明确拒绝。完整边界与验收入口见[资料协议](../specs/project-documents.md)。
