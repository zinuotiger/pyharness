| # | 约束 | 说明 |

## 2. 成本控制手段
| # | 手段 | 说明 |
|---|------|------|
| C-04 | 最大轮数 | 默认 10 轮;防死循环 |
| C-05 | 上下文精简 | 派生历史带窗口;旧轮次摘要(第 5 阶段 compaction 前用简单截断) |

## 4. 如果违反会发生什么
- 违反 C-01(无预算): 死循环/超长任务一次烧几十上百元;本地开发一天不注意几十元
- 违反 C-05(无窗口): 长会话上下文无限增长 → 每轮费用线性上涨 → 10 轮后单轮成本翻几倍
- 面试被问成本控制: 能答"单任务预算+轮数上限+输出有界+模型分级"四件套 = 有工程意识

## 6. 深度场景:长会话成本失控
**根因**: 会话 50 轮后不压缩,每轮把全部历史发给模型。
**连锁后果**: 第 1 轮 ~1K token,第 50 轮 ~50K token → 单轮成本涨 50 倍;一次长任务总成本超预算 10 倍;用户(自己)月底看 API 账单才惊觉。
**正确做法**: 窗口策略(只发最近 N 轮)+ 旧内容摘要(compaction 简化版);第 5 阶段做正式 compaction 前,阶段 3 就用"滚动窗口+摘要占位"。

## 7. 成本计算示例(开发期心算)
| 场景 | 输入 token | 输出 token | DeepSeek 单价 | 成本 |
|------|:---:|:---:|:---:|:---:|
| 简单问答(1 轮) | ~1K | ~300 | 输入 ¥1/M 输出 ¥2/M | ~¥0.002 |
| 工具任务(5 轮, 上下文累计) | ~15K | ~2K | 同上 | ~¥0.02 |
| 整理文件夹演示(10 轮) | ~50K | ~5K | 同上 | ~¥0.06 |
| 失控死循环(无防护, 50 轮) | ~500K | ~50K | 同上 | ~¥0.6+ |

结论: 正常使用单任务 <¥0.1, 预算 ¥1 有 10 倍安全垫; 防护的真正价值是防"失控放大"。

## 8. 模型分级路由策略(第 2 阶段后启用)
| 任务类型 | 模型 | 理由 |
|---------|------|------|
| 简单工具调用/格式化 | deepseek-chat | 快, 便宜, 无 reasoning 开销 |
| 多步推理/代码生成 | deepseek-v4 系列 | 强, 但慢且贵 |
| 备用(主模型故障) | qwen-max | 降级链保可用 |

路由规则: 默认 chat;工具连续失败≥2 次或任务标记 complex 时升级;升级/降级记录进日志(可审计)。

## 10. 预算检查实现要点(伪代码)
```python
class BudgetGuard:
    def __init__(self, per_task_cny: float):
        self.limit = per_task_cny
        self.used = 0.0

    def check(self, usage) -> bool:      # 每轮 LLM 调用后调用
        cost = estimate_cost(usage)      # token × 单价
        self.used += cost
        if self.used > self.limit:
            logger.warning(f"任务成本超限: {self.used:.3f} > {self.limit}")
            return False                  # 循环中止
        return True

    def report(self) -> dict:
        return {"used": self.used, "limit": self.limit,
                "pct": self.used / self.limit * 100}
```
挂在循环每步: 调 LLM → 记 usage → budget.check() → False 则中止并告知用户。

## 12. 成本约束与面试问答联动
**被问"Agent 成本怎么控制"**(必答题): 四件套回答——
1. 单任务预算: 每轮记 token×单价, 超 ¥1 中止(防止死循环烧钱)
2. 最大轮数: 默认 10, 失控必终止
3. 上下文窗口: 旧轮次摘要, 防长会话线性涨费
4. 模型分级: 简单任务走 chat, 复杂推理才上强模型
补充: "我的项目单次演示成本约 ¥0.06, 有 /cost 命令实时可查"——数字比概念有力。
