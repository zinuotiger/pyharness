# 原生窗口与完整工作台

本页对应S18实施候选，验收状态以当前交付报告为准。

使用`pyharness-native`启动原生窗口。原九个页签、会话、审批和运行控制保留；“工作台 → 完整工作台（沿用原账户授权）”会在默认浏览器打开本机完整详情，与原生端共享当前应用服务和队列。

该入口需要同时安装`native`和`web`扩展依赖。缺少Web依赖时基础原生界面仍可使用，菜单会提示依赖不足。首次打开会启用本机HTTP监听，不会自动提交模型任务或重发工具。

本机默认操作者沿用原启动授权。切换到非默认租户后，详情从原账户登录页进入；选择租户名称不代表完成账户登录。团队账户的宿主执行、MCP和管理员配置限制保持原规则。

任务收件箱、执行控制、恢复、任务图、交付、观测、回归与实验均使用原工作台流程。原生端已启动的任务可从详情读取和停止，仍需核对准确运行尝试；停止不代表业务验收通过，也不撤销已发生的外部效果。

关闭浏览器详情不关闭原生程序；退出原生程序时会收尾其自有HTTP服务和共享应用服务。启动失败或关闭未确认时，不自动重发任务；先核对原任务记录，必要时关闭程序后重启。

窗口首次显示按当前可用桌面调整，保留系统任务栏空间。实际高DPI、输入、重启和小屏限制见交付报告；脚本模型、Qt离屏渲染、桌面输入注入与人工测试分别列示。
