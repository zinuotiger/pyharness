# ADR-035：复用原配置权威的版本与兼容回滚

状态：实施中，待当前S16完整验收。依据：已授权总计划P17/E04；前置S15已验收。

模型秘密/元数据与Agent已发布执行声明已有各自权威，不能用另一份任意Settings历史覆盖它们。模型公开参数历史留在原租户设置元数据，Agent配置历史引用原不可变版本及依赖摘要；应用在各自原库的单事务内产生新状态或新发布版本。

不复制秘密值，不恢复外部动作，不热改旧尝试。无效凭据、依赖变化、格式不兼容与未发布草稿冲突应拒绝或明确兼容限制。权限变宽需单独产品确认，并绑定当前资源、历史目标及预览摘要；该确认不取代原任务授权/审批或账户宿主能力边界。

选定模型档案与全局激活档案复用同一公开参数映射。已通过真实两档案和SessionLog回归复现选定模型继承无关激活档案temperature的缺陷；修复映射时保留正式Agent禁用fallback策略与旧接口。规格见[配置版本与兼容回滚](../specs/configuration-revisions.md)，最终完成状态仍以当前源码验收证据为准。
