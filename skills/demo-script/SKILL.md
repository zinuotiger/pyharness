# 桌面演示剧本

## 三场景顺序(每场景 30-60 秒)
1. **整理文件夹**:让 agent 把工作区散乱文件按类型归类(fs 工具真跑)
2. **无人值守**:多任务队列 + todo 清单逐条推进(轨迹时间线回放)
3. **危险拦截**:让 agent 删文件 → guard 拦 → 审批弹窗 → 用户点"拒绝"
   (这是"安全名场面",必须演到)

## 口径边界
- 讲"有"的功能 = 真链 PASS 过的(两条探针:全链工具调用 / exec 审批沙箱)
- 网络技能/多模态/LSP = 主动说"未做,因为…"——砍=安全意识,是加分句
- 演示前确认当前 config(streaming 开/关、权限档位),先说清状态不自称流式

## 每场景开场话术(30 秒版)
- 场景一:"我让它把我桌面工作区的文件按类型整理好——它自己决定用什么工具"
- 场景二:"我派三个任务给它,它排成队列一个个干,中途还自己建了待办清单"
- 场景三:"现在让它删文件——看,guard 拦下来了,弹窗要我批准。我点拒绝"
