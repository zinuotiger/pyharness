# ADR-038 产品控制事实与递增扩展的统一登记

状态：Accepted · 日期：2026-10-21 · 落点：S19 文档与交付收口。

## 背景

租户鉴权 ADR-023 已先占号。产品控制增量曾复用同号，影响引用判定；原始内容完整保存在 [历史原文](history/ADR-023-product-control-log.md)，原字节不改。

## 决策

产品控制的现行编号为 ADR-038，沿用历史原文的唯一 SessionLog、不可变 blob、OS owner lease、CAS 与主体绑定命令键协议。ADR-023 仅表示租户鉴权。所有旧产品领域定义、持久键、事件名和运行数据保持原契约，不因文档编号迁移而变更。

后续能力分别由 ADR-024–037 限定：资料引用、持久尝试、执行效果、恢复、产品 DAG、交接验收、三方写回、观测、数据集、实验、扩展、配置、受控浏览器和原生共享工作台。它们的技术实现与阶段验收到 S18 已完成；S19 的当前最终交付仍须独立通过当前源码验收与新提交 CI。现行入口见 [统一版本交付说明](../user-guide/unified-delivery.md)。

## 后果

唯一注册表仍为 docs/ADD.md；历史原文不再作为现行同号条目。读取者可追溯旧决策，不把旧阶段的“未完成”误读为当前验收结论。

## 违反它的后果

继续用裸 ADR-023 同时表示两份决策会把主体认证与产品控制协议混淆；以文档重编号迁移实际数据则会破坏持久引用和恢复。

## 备选方案对比

不覆盖先占号租户决策，不删旧产品决策，不改事件数据以适配文档编号。采用字节不变的历史副本与新的唯一现行编号。
