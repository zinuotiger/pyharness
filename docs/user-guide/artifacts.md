# Files and artifacts

Upload ordinary input files up to 10 MB into a selected session. Metadata includes size, SHA256, source run/step when known, media/preview type, approval flags and optional retention time. User input uploads may be downloaded directly. Generated patch/test-report artifacts require an export approval. The preview endpoint is bounded for text/JSON/Markdown/patch, and displays ordinary raster images without executing embedded HTML. Markdown uses an escaped basic headings/list/paragraph preview; HTML and executable extensions are not interpreted. Other types (including ZIP) download as attachments, with nosniff and sandbox headers.

A run modifies only its private copy. Text changes generate changes.patch plus an internal hash-checked manifest. Preview Diff, request Apply, approve in the existing approval centre. Baseline changes, foreign ownership, links, traversal or missing manifest reject application. An ordinary partial write failure rolls back the bytes already changed; filesystem crash/concurrent external writers remain documented limits. Delete removes stored bytes and records a deletion fact; expired retention blocks content access. There is no automatic upload to external storage.
