# SYSTEM-IDENTITY — 系统身份与命名锚定

> 类型: 参数锚定(第 2a.5 波) | 用途: 全库对"系统是什么、叫什么、怎么拼"的唯一共识,防子 Agent 命名漂移
> 权威: PRD-Core.md §1 + TECH-ANCHOR.md

## 系统一句话

**PyHarness = 用 Python 从零复刻 DeepSeek Harness 全部功能的单进程 Agent 技术引擎——复刻的是 DSH 的架构决策(事件溯源会话日志、能力三件套 seam、guard 单调拒绝、自研插件总线),不是翻译它的 TypeScript 源码;它是一台"能自己干活、每一步可审计可回放、AI 想干危险事会被拦住"的运行时。**

## 术语统一表(全库必须用左列,禁右列)

| 必须用 | 禁用 | 说明 |
|--------|------|------|
| 事件溯源(Event Sourcing) | 日志系统/记录器 | 核心架构范式 |
| append-only(只追加) | 追加模式/单写 | 日志不可变语义 |
| 会话日志(JSONL 真源) | 会话记录/database | 唯一真相源 |
| guard 单调拒绝 | 权限检查/过滤器 | 只拒绝不放行 |
| 能力 seam 三件套 | 服务接口 | Definition/Provider/Consumer |
| 插件总线 | 消息中间件/队列 | 自研 Cordis 等价物 |
| 核心脊柱(8 模块) | 核心框架/主模块 | 不可换层 |
| 派生视图 | 缓存/副本 | 从日志派生的投影 |
| Desktop 壳(pywebview) | Web 界面/网页版 | 2026-09-06 形态修订 |
| F0xx(F001-F066) | 功能编号自创 | 功能唯一编号 |
| INV-01~09 | 自创不变量号 | 不变量清单 |
| ctx.*(ctx.session 等) | 全局变量 | 服务定位器命名空间 |

## 架构分层命名(全库一致)

```
插件总线(地基,自研)→ 核心脊柱 8 模块(不可换)→ 外围能力层(40+,ctx.* 可插拔)→ 外壳(CLI/Desktop/ACP)
```
