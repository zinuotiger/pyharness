# 外观与动效

页面右上角的“界面皮肤”下拉框可直接选择浅色、深色、星空、樱花、极光、金色、
海洋或科技粒子。小屏保留下拉框；深色和浅色都能直接切回任意粒子皮肤。
设置中的“外观”区域保留相同选择和六张场景预览卡，与顶部入口同步。
场景背景按各自颜色提高显示亮度，聊天背景透明，周围面板使用较轻的玻璃遮罩；
消息正文、输入框和运行详情仍保留深色底以保证可读性。浅色和深色主题保持原样。
切换不刷新页面，不清空草稿、附件或运行状态。“低动效”保留静态场景，“关闭动效”停止动画，
“恢复原主题”回到浅色。

已有偏好会保留；新环境默认科技蓝。系统的减少动态效果偏好会关闭浏览器粒子。
页面隐藏或 WebView 最小化会暂停，恢复窗口不会覆盖用户的关闭选择。粒子模块
缺失时仍可使用静态界面。Native 的“外观”菜单提供对应主题和动效控制。

Web、WebView、Native 分别保存自己的外观偏好，不修改账户、模型或凭据。
物理中文输入、高 DPI、辅助设备和长期设备性能仍需单独人工验收。

Web / WebView 的“设置 → 外观”区域末尾增加“更多背景”。原有下拉框和六张快捷卡仍立即
应用；背景库提供“全部 / 原有背景 / 浅色粒子”分类，点击真实缩略图只临时预览，
“应用背景”才保存。取消、关闭或 Esc 恢复已保存背景，并把键盘焦点返回入口。
“恢复默认背景”先预览新环境默认的科技粒子，应用后保存；原来的“恢复原主题”仍回浅色。
两种恢复操作都保留动效、数量、速度等其他设置。图片加载失败保留可用背景，保存失败
恢复原背景并显示原因。窄窗口中列表独立滚动，底部操作始终可见。

六款浅色粒子为星云、冰湖极光、海蓝、星空、极光和海洋。每款依据独立参考图重建
无文字、无窗口的纯背景，正式 PNG 和真实缩略图分别位于
`theme-kit/scenes/<稳定ID>.png` 和 `theme-kit/scenes/thumbnails/<稳定ID>.png`。
成品均为 1672 × 941 像素，非原生 4K；来源、完整生成提示词、尺寸、大小和哈希见
同目录 `light-particles-provenance.json`。原始参考未修改，也不作为运行资源加载。
新增背景保留明确选择的浅色或深色模式，且不会运行动效。从原有场景皮肤切换时，
移除该场景附带的彩色遮罩，使用浅色内容面板；原场景偏好仍保留，取消即可恢复。
顶部和设置下拉框同步显示当前背景，新增选项带“浅色背景”后缀以区分同名旧场景。
背景库仅加载缩略图，选中后才加载完整图片；仍使用同一个外观偏好存储。
