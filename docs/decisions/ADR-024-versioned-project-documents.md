# ADR-024 — 项目资料、确切引用与交付定义

状态：S05实现决定；本次用户授权持续完成S05–S19。验收状态以当前冻结证据为准。

## 事实与兼容边界

复用ApplicationService→Projects→WorkspaceStore的身份、单所有者锁、OS lease、唯一控制SessionLog和不可变blob。原`workspace.resource_committed`事件增加严格资源种类`document`、`citation`、`delivery_definition`；封套仍schema1，旧七种资源和CMv1/v2、ProductTaskv2均不升级、不改变原命令语义。原事件名、强同步集和旧API保留。S19登记产品控制为ADR-038，原同号产品文本字节不变保存在history目录；ADR-023仍仅属租户鉴权。

纯文本资料只读取确切已准备私有输入。文档保存原始字节摘要，解析器解码UTF8/BOM而不重写原字节。段落、物理页、Unicode码点半开区间和片段摘要固定到精确修订；旧引用不改写。浏览器按Unicode码点处理emoji，与Python契约一致；HTML/Markdown仅作为文字显示。

原文本快照策略`reject-secrets-utf8-v1`不能接收二进制PDF，本次不放宽该策略。PDF另设SourceGrant内明确选择→元数据预览→确认→稳定FD捕获→文本解析→私有保存路径。确认摘要绑定主体、项目修订、grant修订/摘要/序号/根身份和文件元数据；只是本次选择一致性，不是执行或读取令牌。每次真实I/O重新鉴权/核根/查UTC；源目录不得与私有控制存储重叠。

## PDF载体

可信、固定的Python解析脚本只处理任务私有临时PDF，不接受用户命令、不执行PDF动作、不调用模型或网络、不自行产生日志事实。所有领域事实仍由主服务的同一owner产生。与既有Git外部程序适配相同，采用一次性ProcessOwner，Windows隐藏进程和Job生命周期、POSIX独立进程组；它不是Agent、工作者服务、池或第二事件真源。父进程时间10秒，stdout/stderr各最多200000字节，子进程512MiB内存上限，最多200物理页/2MiB原PDF/8MiB累计内容流/96KiB提取文字/400文本块。失败或取消等待有限载体回收，后续不复用旧载体。依赖是uv.lock固定的pypdf 6系列，解析器标识包含实际包版本；包版本变化令旧资料显示stale。

本文将ADR-005的“唯一多进程出口”描述补充为上述**固定系统文件解析适配器**的窄范围例外，依据为本轮受权S05文本层PDF需求及不可信内容的资源边界。主服务、Agent、队列与治理继续同进程；不改变执行工具的guard/审批要求。没有通用外部命令、端口或自主子进程权限。

加密、损坏和无文本层PDF明确不可定位，不执行OCR；页面索引为真实PDF物理页，空白页保留其位置。JavaScript、自动动作、启动/提交/外部文件动作和嵌入文件拒绝；普通URI/内部跳转只被忽略，绝不执行。只交付提取文本阅读与引用，未交付原PDF像素级版式渲染、Office阅读或OCR。格式能力在界面和规格明确，不能以文本抽取声称视觉排版保真。

## 资料生命期与交付定义

当前版本、被新修订替代、项目/输入/解析器变化、文件元数据变化、源文件缺失和资料退役分别观察；失效历史不自动换新正文，缺失/退役不显示旧正文。授权撤销、过期、角色/租户/主体变化和归档拒读。活宿主正文只在明确PDF导入时读取；日常阅读/引用只读私有捕获字节，活源仅查元数据，未宣称能识别刻意恢复全部元数据的宿主篡改。

引用为不可变第一修订，固定doc ID/revision/digest/source_seq、block和区间/quote_digest。交付定义CAS修订，绑定正式ProductTask和确切引用；旧context_reference_only不能冒充正式任务。`acceptance_status=not_evaluated`、不授权执行/下载，S10才接独立交付验收，S11才安全写回。

所有写入先确认blob，再强同步同一SessionLog并核对磁盘。回执未知保留原键/正文，重开原键核对/重试，不盲目新建；Web当前未知命令仅内存保存，完整浏览器退出后可从服务端列表及确切历史GET核对。S06另交付持久提交查询。列表复用50条有界水位/主体绑定游标，末尾汇总所有依赖授权查UTC。不同主体的私有资料不可互读。
