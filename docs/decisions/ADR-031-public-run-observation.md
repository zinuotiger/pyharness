实际出站观察是原执行JSONL中的新不可变事实，记录有界、严格脱敏的实际adapter输入或transport payload及其身份/阶段/裁剪信息。它不构成第二份消息历史，不参与derive_messages，不作为恢复提示词或未来执行权限；模型历史仍走原SessionLog、组装器与原唯一LLM入口。预备请求不宣称已经到达提供方，提供方响应与未知情况分别标记。旧日志没有观察事实即不可用，不能从今天的配置或资料重组假历史。

只读派生包装与请求作用域的不可变计数用于核对真正加载/截断情况；不得修改历史或创建共享权威cache。只允许公开字段，固定脱敏不受关闭旧日志脱敏选项影响；隐藏推理、认证头、原始响应、异常正文及图片字节不入公开记录。受限模式并非完整DLP，无法安全表示则整项withheld。窗口裁剪、观察副本展示裁剪和未知分别表述。

权限预演仅预测原固定策略、输入与参数的结果，不装载执行Provider、不申请审批、不产生执行权限；无法在零副作用条件下判定的能力明确unknown，shell及任意插件行为不猜测。实际调用继续经过原schema、scope、Guard、审批与Provider入口，并以调用时权限重查。

运行比较要求相同精确输入与验证器，Agent/模型/配置版本差异单列为比较维度；不一致或资料不足返回不可比，不制造质量结论。未知token/费用为null，执行状态、外部效果、业务验收分开。数据集白名单断言与批次实验由S13/S14接入。

所有新观察读取沿原Projects/WorkspaceStore授权和严格只读执行日志读取器，前后核对实际Actor及当前来源权限。复用原事件及控制事实，不新增数据库、队列、引擎或模型调用入口。新增独立事件模型保持全部旧事件Schema与原强同步集不变；必要观察用显式sync，不扩张执行权限。

原H05/INV01唯一历史、Guard单调与账号host执行限制保持。新增预演/公开投影仅替代“没有产品观测工作台”的历史排除范围，不豁免原安全边界。验收以当前源码的正负例、真实renderer/HTTP/本地传输、独立安装、全量与16核心覆盖、原树保全及全会话归档为准；模拟推理与付费外部调用分列。
