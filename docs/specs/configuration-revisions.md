# 配置版本与兼容回滚（S16）

状态：实现与验收中。本规格不代表S16或整个计划完成。

## 资源与权威

模型档案公开参数的历史存在原TenantSettingsStore元数据中；秘密仍由原加密库及凭据代次管理。Agent配置历史引用原不可变已发布AgentVersion，并记录其模型与扩展依赖摘要；原PlatformStore保持唯一配置权威。每次应用在对应原库的一个事务中提交，不宣称跨两库的原子整体回滚。

历史覆盖模型档案公开参数、激活选择及Agent已发布执行声明。宿主路径、秘密值、技能/知识正文、MCP程序内容、运行记录和已发生的外部动作不由配置回滚重建。历史不是秘密备份，也不是执行授权。

旧引擎上下文和已创建尝试保持原固定配置；后续新任务可选择新配置/Agent版本。若原凭据或执行绑定机制判定旧尝试失效，仍拒绝并要求新尝试，不能为了“继续”放宽原边界。

## 固定模型参数

全局激活档案与Agent明确选择的档案使用同一公开参数映射。Agent选择模型档案时，模型、地址、凭据引用、temperature和max_tokens来自该档案；历史缺失字段回落到调用者基础配置，不能从无关激活档案继承。正式Agent继续保持原禁用fallback策略，调用者Settings不被修改。

## 记录、预览与读取

记录由服务端根据当前已保存的模型档案或原Agent已发布版本派生，不能上传任意Settings或秘密历史。记录包含版本格式、租户、资源身份、精确源摘要、时间、原凭据代次/依赖绑定，历史不可原位编辑。列表和差异返回有限公开字段；固定上限和明确错误代替静默删除旧记录。

预览不启动模型、Provider、引擎、队列、MCP程序或浏览器，不发送网络请求。只比较当前与选定历史资源，检查格式兼容、凭据代次/端点/实际可用性、依赖摘要及当前权限。过期、删除、损坏、不可核对的秘密引用不能自动替换成当前秘密。无法固定代次的宿主env/file引用应明确标识恢复限制，不把存在的环境变量冒充旧秘密版本。

Agent历史引用原版本，不能覆盖旧AgentVersion。模型/MCP/技能/知识依赖变化必须明确指出；依赖核对是当时的观察，不承诺对外部可变文件的OS级原子快照，新任务仍按原实际执行路径重新检查和固定。当前未发布草稿不得被回滚默默覆盖，应提示先处理草稿。

## 应用与权限扩大

应用请求绑定当前资源摘要、选定历史版本与预览摘要；服务端在原事务内重新检查。仅确认布尔值必须是真正bool，客户端自报角色、租户、权限判定或执行标志无权威。沿原账户权限派生主体，写操作后或跨await后重新查当前身份；查询历史和同键结果也需要当前权限。

列出权限扩大项：策略变宽、工具/连接/技能/知识能力增加、审批或证据要求变弱、沙箱/宿主或Codex执行边界改变、预算/回合/时限增加等。未知变化不得静默当作收紧；需要扩大确认时，该确认与本次目标/当前状态/预览摘要绑定。配置确认不能替代任务工具审批，也不能突破原账户禁止宿主执行的策略。

成功应用产生新的配置状态或新的Agent发布版本，不改旧版本、尝试、检查点、执行收据、交付验收或外部文件。命令键及其公开结果随同一原事务提交；未知结果先按原键查询，不能盲目重发。密钥轮换、撤权、预览后配置变化、跨租户、未来格式、篡改摘要和冲突均须拒绝。

## 验收与限制

正常与反例必须覆盖真实两档案参数、原秘密字节/旧历史/旧日志保真、跨租户及撤权、权限扩大未确认拒绝、同键冷查询无重复发布、过期预览拒绝、至少两实例和独立进程锁对抗、Producer→记录→预览→原权威应用→新任务配置的实际可达性。界面需真实渲染器关键交互、控制台和宽窄截图；冻结后全量回归与16核心门、兼容检查、全新安装以及原四个来源工作区保全另行留证。

受控适配器证明接线和授权边界，不能冒充付费模型质量、真实物理IME或监视器DPI验证。实际完成点、失败及外部限制以当前冻结证据报告为准。
