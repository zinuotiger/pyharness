# 使用任务收件箱

1. 在项目空间准备私有输入，在“正式产品任务”保存绑定输入的任务。未绑定草稿不提交、不执行。
2. 打开“任务收件箱”，展开“提交新尝试”，选择任务修订及可选资料、引用和交付清单；清单内的引用和资料一并固定。
3. 点击“提交运行尝试”。服务端原键读回一致后才显示“持久确认”。本阶段不启动模型/工具；提交成功不等于执行或交付验收成功。
4. 结果未确认时保留原提交键，用“只读查询”核对；确需重试时使用“原键原选择重试”。刷新页面后恢复线索仍只是引用元数据，必须重新鉴权，系统不自动重发。
5. 列表可查看原修订。后续资料/任务变更显示失效，不把原提交换成新版。授权/角色/来源失效时拒读，复制key或换Agent名不能绕过。

若提示写入端需重开，表示故障隔离仍生效。保留原键和数据，正常关闭重开后先查询，不删除日志、不新建替代提交。浏览器存储不可用时，可手动输入原key或从服务端列表核对。
