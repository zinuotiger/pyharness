# CONSTRAINTS-08 — 生产故障模式

> 类型: 参考 + 设计约束 | 权威: DEP.md 故障排查 + PRD 风险章
> 适用: 全部阶段,面试"线上出问题怎么排查"弹药库

## 1. 十大故障场景(每场景: 症状→诊断→修复→预防)
| # | 场景 | 一句话处置 |
|---|------|-----------|
| F-01 | LLM API 全挂 | 降级链双模型都失败 → 返回 LLM-399,告知用户稍后重试 |
| F-02 | 单模型限流 | 指数退避+切备用;429 不重试同一模型 |
| F-03 | 会话日志损坏 | 加载器检测截断 → repair 或拒读;备份可恢复 |
| F-04 | 磁盘满 | JSONL 写失败 → PERS 错误提示清理;日志有告警 |
| F-05 | 进程崩溃 | 强同步事件已落盘 → 重启恢复;丢的只有未 flush 中间态 |
| F-06 | 死循环(模型失控) | 最大轮数触发 → 中止,告知用户 |
| F-07 | 成本超限 | 预算检查触发 → 中止,告知用户 |
| F-08 | 配置错误 | 加载时校验失败 → 明确报错指向配置行,不静默用默认值 |
| F-09 | 工具执行挂起 | 工具级超时 → 掐掉返回错误给模型 |
| F-10 | 备份恢复 | 会话目录备份 → 拷回 → 重启验证回放一致 |

## 2. 故障可观测性
| # | 约束 | 说明 |
|---|------|------|
| FR-01 | 日志分级 | DEBUG/INFO/WARN/ERROR;错误必带错误码 |
| FR-02 | 会话可回放 | 任何故障排查第一动作: 回放会话日志定位断点 |
| FR-03 | 状态可查 | CLI 提供 /status(当前任务/轮数/成本) |

## 3. 如果违反会发生什么
- 无 FR-02(不回放直接猜): 排障靠猜 → 定位慢 10 倍,还可能修错地方
- 无 F-06(死循环无上限): 一次失控烧钱 + 占住进程,用户无法打断

## 4. 深度场景:AI 失控死循环
**根因**: prompt 注入或模型故障,AI 不停调工具不结束。
**连锁后果**: 无轮数上限 → 无限调用 → 成本爆炸 + 工具副作用重复执行(反复写同一文件/反复调外部 API);进程被占,用户输入无响应。
**正确做法**: 最大轮数(默认 10)+ 每轮成本检查 + 用户 Ctrl+C 可中断;三者齐备,失控在 10 轮内必然终止且可解释(日志显示触发了 max_turns)。

## 6. 故障排查标准动作(排障 SOP 第一版)
```
1. 看状态:  /status —— 当前任务/轮数/成本/最后事件 seq
2. 回放:    读会话 JSONL 尾部 —— 崩溃前最后发生了什么
3. 查错误:  grep "ERROR" 日志文件 —— 错误码是什么
4. 对码查:  对照 ERR.md 诊断流程(症状→根因→修复)
5. 复现:    最小复现(同输入重跑, 或 mock 故障源)
6. 修复+回归: 先写失败测试证明 bug → 修复 → 测试绿
7. 沉淀:    新故障模式 → 更新本文件 + DEP.md
```

## 7. 演示环境故障预案(面试录屏前必查)
| 检查项 | 命令 | 失败预案 |
|--------|------|---------|
| API key 有效 | 先跑一次 1 轮问答 | 换备用 key; 录屏用真实 API 前先 warmup |
| 网络稳定 | ping api.deepseek.com | 手机热点备用 |
| 演示场景可复现 | 场景脚本跑通 ≥2 次 | 失败用上次录屏(提前声明) |
| 日志可展示 | 打开会话 JSONL | 展示文件结构即可 |
| guard 拦截演示 | 单独跑"AI 试图删文件"场景 | 此场景用 mock 模型保证必现 |

## 9. 故障模式与错误码速查表
| 症状 | 错误码 | 根因域 | 第一动作 |
|------|--------|--------|---------|
| AI 不回复 | LLM-301/399 | 模型 | 查 API 状态+日志 |
| 工具不执行 | TLB-801/802 | 工具 | 查模型原始 tool_call |
| 危险操作被拦 | GRD-401 | 安全(正常) | 确认是预期拦截 |
| 重启失忆 | PERS-2xx | 持久化 | 查 JSONL 完整性 |
| 配置不生效 | CFG-601 | 配置 | 查配置层级覆盖 |
| 成本异常 | LLM-305 | 成本 | 查轮数与 token |
| 审批无响应 | APR-501 | 审批 | 查审批超时策略 |
| 事件写入失败 | EVT-105 | 会话 | 查磁盘+格式 |


## 10. 故障模式演练清单(面试前自测)
- [ ] 拔网线跑一次 → 应出现超时→重试→降级→(双挂)LLM-399, 不崩溃不静默
- [ ] 手动截断 JSONL → 重启应报 PERS 错误或 repair, 不静默丢数据
- [ ] 把 max_turns 设 3 跑长任务 → 应在第 3 轮终止并说明原因
- [ ] 配置填错 key → 启动应报 CFG/凭据错误指向 env 名
- [ ] 让 AI 调危险工具 → GRD 拦截 + 审计日志有记录 + 函数零执行
- [ ] 长任务中途 Ctrl+C → 应可中断, 重启后强同步事件不丢
