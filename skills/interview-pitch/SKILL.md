# 面试叙事

## 核心口径(不可打破)
- 对外身份:六年测试功底 + 四个月 AI 全栈转型,三项目实战(比特鹰/RAG+Full-Pipeline+evleven 等案例)
- 不主动提"十年空窗";被问空窗 → 转"回归家庭期间保持学习与项目管理能力"
- 每个项目只讲三件事:做了什么 / 我负责哪块 / 结果怎么验证

## 组织流程
1. 开场定身份:测试底子(找 bug 的眼睛)→ 转型动力(自动化测试遇见 AI)→ 三项目
2. 项目讲述按"主线一事件溯源 / 主线二工具安全 / 主线三测试方法论"切
3. 每讲完一段,主动留钩子问面试官:"这块要不要展开?"

## 红线
- 只讲真链验证过的功能(探针 PASS 的两条链);"框架在/未实装"主动坦白
- 不编造医生、时间、数字之外的具体承诺;薪资先不主动报价,被问先反问区间
