# ADR-032：确认后的失败用例与不可变数据集修订

状态：S13候选2已验收及完整可读取归档。依据总计划D04/L01；S14及以后独立推进。

失败记录先经原Projects授权、原执行日志严格读取器及当前来源门生成有限公开候选。只有实际执行失败或有效的独立业务验收失败可以进入候选；取消、失联、未知及成功不能被改名为失败。原请求没有公开观察时标记不可用，不用今天配置重建历史。候选固定实际主体、租户、执行授权引用、原日志前缀与摘要；业务失败另固定原独立验收引用。

操作者填写可用的人工复现输入和白名单期望，明确确认确切候选摘要后保存。人工输入不冒充原始完整请求；有界过滤、隐藏、裁剪或不可用状态独立显示。有限秘密模式检查不是完整DLP。Case保存及数据集操作不调用模型、工具、队列或第二执行器，历史工具事件只作为数据，永远不自动重放。

新增`regression_case`与`regression_dataset`两种严格控制资源，由原`workspace.resource_committed`事件、唯一control writer、命令幂等、不可变digest blob和提交确认机制承载。原30种具体资源模型保持；共享控制信封resource_kind枚举与审计筛选显式增加两个值，不声称该信封JSON Schema逐字节不变。事件种数仍90、强同步词表仍22。新程序读取旧日志；旧程序不保证理解新资源，回退必须使用对应旧数据快照。投影只在一次原日志重放的局部变量中累积用例历史，用以证明数据集引用在当时已存在；不新增历史数据库、共享权威cache或后台任务。

Case编辑生成新修订；Dataset引用确切Case ID、修订、digest与source_seq。读取旧Dataset时沿原控制事件读取旧Case，不能默换最新版本。历史投影验证当时事实与所有者，不把今日撤权、保密规则或验收后续变化写成旧日志损坏；历史文本模型只检查固定结构。候选两侧文本重用原秘密文本检查，受限即标withheld，不从旧公开副本直接放行。保存、读取、导出和导入再检查当前Actor/tenant/来源、人工字段及保存证据两侧文本；今日受限的旧副本拒读、目录隐藏正文，但项目列表及原控制历史仍可解析。源日志、引用或摘要无法核对则拒绝，公开副本不能绕过撤权。

断言仅支持有限文本包含/排除/相等、字面JSON Pointer标量相等、确定执行终态检查。拒绝表达式、脚本、任意JSONPath、额外字段、非法指针、类型混淆及超限。重复JSON键不作明确证据。缺失、取消、过滤和不完整证据不产生通过；S14的批次分母另按真实执行状态核验。

界面和显式导入导出已接线并通过候选2整体门禁；导入仅验证本地可证明的完整Dataset/Case版本，再新增一次Dataset引用修订，不从文件自动创建Case。限制、固定格式、当前完整证据及历史失败见[失败与数据集契约](../specs/regression-datasets.md)。完整4235项回归（4189通过、46条件跳过）、323Chrome、486运行文件独立安装、原树保全、恢复包及全会话可读取归档均已核对；这是本机合成推理与受控真实操作的验收，不冒充付费模型质量、物理设备条件或独立人工审查。
