# ADR-034：沿用原执行边界的扩展诊断

状态：实施中，S15 验收前不得标记已交付。

MCP 已有连接及工具桥，技能已有扫描、装载及正式上下文注入。本变更增加独立观察入口，不替换这些运行权威。

配置预览不创建进程；发现须本地操作者对当前配置摘要明确确认，独立拥有原 StdioTransport，使用原 McpClient 握手和 ToolRegistry 编译，仅发送 initialize/initialized/tools/list，最后关闭进程。发现结果是历史观测，不代表当前连通。受管与静态运行配置以不同来源标识，配置变化后旧观测失效。未确认命令保留且不自动重放；同键重复仅观察。

参数预览复用原严格 schema 校验，不返回参数值，不绑定运行 Provider，不调用工具，必须说明实际执行仍受原 scope、guard、审批、预算及效果收据约束。

技能路径先复用根目录 containment 约束再读取；加载快照保留原 load 文本及截断规则，版本证据明确区分源文件与实际加载视图。隔离演练只能使用原工具执行管道和独立会话，不改正式文件/权限；受控脚本模型只验证接线，不证明模型质量。

诊断元数据使用原 PlatformStore 的 preferences；真实任务和演练事件仍使用原 SessionLog，不新增生产执行日志或远端调用入口。HTTP 入口重新核对当前操作者身份，租户成员不因新入口获得宿主进程权限。恢复/冷启动不能把缺少结果的发现重新执行或称为成功。
