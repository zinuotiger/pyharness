# 依赖任务图

在项目空间点击“依赖任务图”。先准备已绑定输入的正式任务和已发布 Agent。增加节点，填写 ID，并用逗号列出其上游 ID；例如 A 无依赖、B/C 依赖 A、D 依赖 B,C。可以分别固定资料、引用与交付定义。

保存图版本后，先执行前预检。页面显示节点边界及全部已发布 Agent 额度之和；图额度不足、引用变化、价格未知会被拒绝。编辑定义后须重新保存并预检。宿主执行需明确勾选边界确认，再点击“授权并开始图运行”。

运行视图显示固定节点与依赖关系，编辑器会收起，便于观察状态。刷新只读取当前节点日志。completed 是技术完成；独立业务验收按后续交付链核对。依赖边本身不把上游文件复制给下游。

若提交回执丢失，使用“按原键查询”或“重试原命令”，不要创建另一张图或换键冒充恢复。浏览器重开只加载列表与待核对线索，不自动开始。运行列表可以观察原图授权；重启后的未完成节点显示中断，不会自动重跑。图节点的通用续做目前明确阻塞，普通独立任务的 S08 续做仍可用。

停止当前图会先保存停止请求，再停止已经准入的实际节点并阻止新节点。来源撤权后正文清除，同主体仍可核对最小停止引用；无法确认实际终态时不能把停止请求当成已停止。切换主体或关闭窗口会丢弃迟到响应。
