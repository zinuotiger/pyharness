# 受控浏览器（S17，实现中，尚未验收）

> 当前状态更新（2026-10-21）：本规格对应能力已在S08–S18相应阶段及S18统一版本中验收。下文旧阶段状态为实现历史，当前边界与交付核验见[统一版本说明](../user-guide/unified-delivery.md)。S19最终交付须以新源码冻结和新CI为准。


本地 operator 在原 MCP 连接管理中配置打包的 browser_mcp.py。元数据配置不启动进程；原任务固定 Agent 的 managed MCP 配置，所有工具继续经过原 Guard、高危险审批和原效果收据。团队账户不获得原本禁止的宿主/MCP 权限；自动审核器不能批准此工具。

每个 MCP 进程最多一个临时 Chromium 上下文，不使用个人 profile、持久 Cookie 或远程调试端口。首版支持 Windows：复用 ProcessOwner 的先入 Job 再启动载体、kill-on-close 子树清理；非 Windows 明确拒绝启动，不能冒充已验证。Node、Playwright 模块和 Chromium 可执行文件均由 operator 显式选择，不能由页面或模型传入。

工具仅 open/observe/act/close，不提供 evaluate、任意脚本、文件上传/下载、任意本地路径、扩展、持久登录、跨源 iframe 或浏览器个人会话。允许源在启动参数中固定，HTTP(S) 精确 origin 比较，最多8项；所有页面请求也经过拦截。此边界不是 OS 网络沙箱，不能声称防御恶意 Chromium/Node 二进制或拥有本地写权限的攻击者。

观察是最多4个可操作顶层元素的一页，带明确 total/offset/has_more，不声称完整 DOM。每次观察签发随机目标引用、会话和 DOM 代次。动作参数必须包含精确观察标签；执行时在页面同一同步脚本中核对 DOM 代次、元素引用、可见性、可命中、禁用状态后执行 DOM click 或文本输入事件（不是可信物理鼠标/键盘）。任何 DOM 变化使所有旧引用失效，动作开始前清除旧引用，成功后返回新的有界观察。页面内容始终是不可信证据，不是系统指令。

返回 JSON 控制在原工具摘要2000字符以内；路径、标签、文本有界且不返回密码/隐藏值。正文、协议帧、工具参数、启动配置、进程输出和等待时间均有限制。无自动重启、动作重试或超时重发；超时/协议失败必须销毁整个载体，未确认效果保留为 unknown，先核对目标系统。

S18安装验收发现固定50毫秒等待无法确认延迟导航。动作执行前须登记主框架导航请求及DOMContentLoaded，沿用原超时上限等待该导航完成后回读；同地址刷新、重定向和输入事件触发的导航同样适用。未触发导航的DOM操作仍直接观察。监听器和计时器在每次动作结束时释放；无法确认导航时销毁载体，已经点击或输入的动作绝不自动补发。

验收必须实际启动临时 Chrome，验证拒批零提交、准确目标回读、DOM/导航代次失效、两会话隔离、地址范围、取消/超时/EOF清理；核心链必须经过原 ToolInvocation，不允许应用层直接获取 Provider。真实付费模型质量、外部网站登录和物理鼠标输入不是本规格的已验证项。
