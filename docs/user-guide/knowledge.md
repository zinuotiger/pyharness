# Knowledge providers

ExactKeywordKnowledgeProvider is the default. Upload UTF-8 text/Markdown/JSON/CSV (up to 1 MB), inspect indexed/version state, retry local indexing, replace a version or delete an unbound source. Query returns source ID, name, line, quote, version and diagnostics. No match returns answer_allowed=false and no_reliable_evidence. Agent versions bind selected source IDs and receive cited evidence as data, never as instructions.

RemoteRagKnowledgeProvider is optional and not needed at startup. Add a remote_rag connection, explicitly enable it, then switch provider. POST <endpoint>/query receives {query, documents, source_ids, limit:10}; response is {citations:[{source_id,quote,...}], answer_allowed:boolean}. Requests use a five-second timeout, no redirects/environment proxy and a 64 KB response cap. Quotes must occur in selected local documents. Unavailable/invalid responses fail closed; switch back to exact_keyword explicitly. This MVP transfers documents at query time, without a remote ingestion queue. Endpoints requiring unsupported contracts need an adapter. No rag-engine code is copied; BGE semantic experiments are not the default reliable retrieval strategy.
